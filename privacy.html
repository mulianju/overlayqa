What the extension does

OverlayQA draws image layers on top of a page so you can compare a design export with the implementation. You choose the images. The extension does not crawl the web and it does not include analytics, advertising, or a user account.

Data that stays on your device

Mockup images are stored in IndexedDB inside the extension. Layer position, opacity, scale, blend mode, folders, and notes are stored in chrome.storage.local, keyed by site origin or path. A Figma personal access token, if you save one, stays in chrome.storage.local. None of these are uploaded to us.

Data that leaves the device

If you activate Pro, the extension sends the license key and a random instance name to the license Worker you configure. That Worker sends the key to Creem to activate, validate, or deactivate it. The Worker does not receive your images. If you import from Figma, the extension sends your token and the file request only to api.figma.com, then downloads the exported PNG from the URL Figma returns. That download is not proxied through our servers.

Permissions

The extension asks to run on http and https pages so the overlay can be drawn, and to use storage, scripting, activeTab, and alarms. The content script stays idle until you enable OverlayQA on that origin. file:// pages work only if you turn on “Allow access to file URLs” in chrome://extensions. We do not sell personal information and we do not use it for cross-context advertising.

Retention and deletion

Local data remains until you delete a layer, deactivate the license, or remove the extension. Deactivation asks the Worker to deactivate that browser’s license instance and then deletes the local license record. Creem keeps the purchase record under its own policy.

Children

OverlayQA is a developer tool. It is not directed at children under 16.

Changes

If this policy changes in a material way, the date above changes and the Chrome Web Store listing is updated.

扩展做什么

OverlayQA 在网页上绘制图片图层，用来对比设计导出图和实现。图片由你自己选择。扩展不会爬取网页，也不包含分析、广告或用户账号。

留在设备上的数据

设计稿图片存在扩展自己的 IndexedDB 里。图层的位置、透明度、缩放、混合模式、文件夹和批注存在 chrome.storage.local，按站点来源或路径区分。如果你保存了 Figma 个人访问令牌，它也只在 chrome.storage.local 里。这些都不会上传给我们。

会离开设备的数据

激活 Pro 时，扩展会把许可密钥和一个随机实例名发给你配置的许可 Worker。Worker 再把密钥发给 Creem，用于激活、校验或停用。Worker 收不到你的图片。从 Figma 导入时，扩展只把令牌和文件请求发给 api.figma.com，然后从 Figma 返回的地址下载 PNG。这个下载不经过我们的服务器。

权限

扩展需要在 http 和 https 页面上运行，才能把叠层画出来，并使用 storage、scripting、activeTab 和 alarms。在你为该来源启用 OverlayQA 之前，内容脚本保持空闲。file:// 页面只有在 chrome://extensions 里打开“允许访问文件网址”之后才能使用。我们不出售个人信息，也不把它用于跨场景广告。

保存和删除

本地数据会保留到你删除图层、停用许可或卸载扩展。停用时会请 Worker 停用这台浏览器的许可实例，然后删除本地许可记录。Creem 按其自己的政策保留购买记录。

儿童

OverlayQA 是开发工具，不面向 16 岁以下儿童。
